# 1.ipynb ~ 7.ipynb 에서 실제로 import 하는 패키지만 모은 목록입니다.
# 버전은 현재 .venv 에 설치되어 동작이 확인된 것과 동일하게 고정했습니다.
# (requirements-windows.txt 는 책 전체(비전/서빙 포함)용이고, 이 파일은 지금 노트북 전용입니다.)
#
# 설치 (Windows + RTX 50 시리즈 + Python 3.11):
#   uv venv --python 3.11 .venv
#   uv pip install --python .venv\Scripts\python.exe torch==2.7.1 --index-url https://download.pytorch.org/whl/cu128
#   uv pip install --python .venv\Scripts\python.exe -r requirements-notebooks.txt
#
# 주의:
#   - konlpy 는 JDK(자바) 설치 + JAVA_HOME 설정이 따로 필요합니다.
#   - nltk 데이터(punkt, punkt_tab, averaged_perceptron_tagger[_eng], wordnet, omw-1.4)는
#     노트북 안의 nltk.download(...) 셀에서 받습니다.
#   - torchtext 는 여기 넣지 않습니다. 마지막 릴리스 0.18.0 이 libtorch 2.3.x 에
#     ABI 로 묶여 있어 torch 2.7 에서는 import 자체가 안 됩니다(WinError 127).
#     반대로 torchtext 가 붙는 torch 2.3.1+cu121 은 RTX 50 시리즈(sm_120)에서
#     CUDA 커널이 뜨지 않습니다(cu121 빌드는 sm_50~sm_90 까지만 포함).
#     -> torchtext API 가 필요하면 이 저장소의 torchtext_compat/ 을 쓰세요.
#        GPU + torchtext API 용 환경:
#          uv venv --python 3.11 .venv-torchtext-cuda
#          uv pip install --python .venv-torchtext-cuda\Scripts\python.exe torch==2.7.1 --index-url https://download.pytorch.org/whl/cu128
#          uv pip install --python .venv-torchtext-cuda\Scripts\python.exe -r requirements-notebooks.txt
#          # site-packages/torchtext_compat.pth 가 `torchtext` 이름을 연결해 줍니다
#     .venv-torchtext(torch 2.3.1+cpu) 는 진짜 torchtext 를 CPU 로 돌리는 대조군입니다.
